# Oxyra 面试 TikTok 作业

我在这个仓库中提交作业一「自动化 Pipeline 设计」与作业二「Vibecoding」的源码。三个模块已合并为一份中文 PDF，通过面试系统提交。

## 在线体验

- **[作业二：微笑下雨、大笑烟花](https://oxyra22.github.io/Demo/)**
- [其他 Vibe Coding 尝试：小幽灵互动](https://oxyra22.github.io/Demo/premium/)

点击 Open Camera 并允许摄像头权限，保持自然表情完成校准，再微笑、大笑或移动头部。Play Demo 可直接查看模拟效果。面部识别在浏览器本地运行，摄像头画面不上传。

- [作业二：互动原型](./part2/README.md)：微笑雨效、大笑烟花、移动头部碰撞，含本地运行步骤、模型及素材。
