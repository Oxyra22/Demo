# 作业二 · Vibecoding

作者：Oxyra  
版本：H30-dream-clouds

我把题目落实为三项互动：微笑下雨、大笑绽放烟花、烟花粒子与移动头部碰撞。我使用浏览器端面部识别和二维粒子物理，视频与关键点留在访问者自己的浏览器中。

## 我提供的入口

- 主作业路径：`/`。点击 **Open Camera**，允许摄像头并以自然表情完成校准，然后微笑、张口笑、左右移头。
- **Play Demo**：使用黄色模拟头像播放雨和烟花，适合检查画面；这条路径没有真人输入。
- **Reflection**：我的 200 字内复盘与核心纠偏提示词，也见 [RETROSPECTIVE.md](./RETROSPECTIVE.md)。
- `/premium`：我保留的小幽灵额外探索，使用图片分层和程序动画。它与三项题面验收分开，完整 PDF 作业说明中未展开。

## 在自己的电脑运行

我使用 Node.js 22.13 以上版本和 pnpm 10。首次安装依赖需要联网。请在本文件所在的 `part2` 目录执行：

```bash
corepack enable
corepack prepare pnpm@10 --activate
pnpm install --frozen-lockfile
pnpm build
pnpm preview:node
```

然后在浏览器打开 <http://127.0.0.1:4173/>。Chrome、Edge、Safari 等浏览器会请求摄像头授权；允许后保持面部自然放松，等到 Ready 再开始测试。

模型、运行时和美术素材都在 `public/`，无需自行寻找或配置 API 密钥。摄像头需要 `localhost` 或 HTTPS 安全环境。手机访问电脑的普通 HTTP 局域网地址通常无法使用摄像头，应使用已开放的 HTTPS 部署。

我提供的 Node 预览会保存完整构建快照；再次修改并构建后，停止预览命令并重新启动，即可使用新版本。`pnpm dev` 依赖 Cloudflare Workerd 支持的系统版本；旧版 macOS 可使用上述构建与 Node 预览流程。

我以受控输入验证表情映射、碰撞数学、校准、权限失败与资源清理。当前版另通过 32 项自动化界面检查，覆盖桌面、360/390 像素布局、演示顺序和拒权恢复；该界面测试使用模拟拒权输入。

我的 2026-09-13 真人录屏显示一次摄像头开启、微笑下雨和较大笑容烟花。录像没有显示构建号，因此我将其作为迭代证据。当前版多人表情准确率、真实移动设备帧率、完整连续碰撞轨迹与持续温升还需要补证。H30 微调通过 34 项界面检查，加入避开头部的缓存蓝紫小云、约 10% 雨丝微光、烟花细闪和统一可关闭浮层；小幽灵在摄像头识别到人脸后自动循环。

## 我的实现与边界

- 我用嘴角和张口特征估计笑容，微笑保持约 140 ms、大笑保持约 180 ms 后触发；当前没有独立的牙齿分割模型。眨眼为额外触发方式。
- 我将镜像后的脸部轮廓投影为移动椭圆，为粒子处理重力、速度、阻力、寿命及反弹；这是屏幕空间物理近似，肩膀和手尚未接入。
- 我给推理频率、粒子数量、像素比、星空绘制和效果寿命设定预算。推理采样率与渲染帧率分别统计，目标值与实测值分开。
- 我在隐藏页面、取消、关闭及异常时处理资源释放；视频与识别器迟到返回也会被取消会话接管并清理。
